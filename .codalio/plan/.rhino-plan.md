# Implementation Plan: SnapDo

<!-- previous-plan: fd4ed502ea45fecde10e6ffdaa20fc5b0431e6fb54a4d0c8dab5eefd2aaba094 -->

## Summary
SnapDo is an ultra-minimalist task management application offering sub-second capture via instant text input and hands-free Siri / Google Assistant voice integration. Built on Rhino on Rails, it features fluid gesture triage, OLED dark mode, offline queuing, automated 90-day task retention archival, and real-time telemetry.

## Extras (NOT covered by blueprint — develop stage implements these by hand)

- **Voice Capture API Webhook Endpoint** (`POST /api/v1/voice-capture`)
  - **Rule**: Accepts JSON payloads from Siri / Google Assistant shortcuts, parses text & natural language dates, creates a Task, and writes a VoiceCommandLog entry.
  - **Where code lives**: `server/app/controllers/api/v1/voice_captures_controller.rb`
  - **Acceptance criterion**: AC-26 & AC-33 (Siri & Google Assistant voice task payload execution)

- **Natural Language Date Parser**
  - **Rule**: Intercepts task creation payloads containing date strings (e.g., "tomorrow at 5pm") and parses them into `due_at` timestamps.
  - **Where code lives**: `server/app/models/concerns/natural_language_date_parser.rb`
  - **Acceptance criterion**: AC-20

- **Automated 90-Day Task Archival Filter**
  - **Rule**: Active API listings for task retrieval automatically filter out completed tasks older than 90 days (`completed_at IS NULL OR completed_at > 90.days.ago`).
  - **Where code lives**: `server/app/models/scopes/task_scope.rb`
  - **Acceptance criterion**: AC-69, AC-70, AC-71, AC-72, AC-73

## Implementation order (recommended stage flow)

1. **Plan** — Complete blueprint YAMLs, ui-handoff.json, acceptance-criteria.json, and index.json.
2. **Develop** — Phase A: Run `bundle exec rails rhino:blueprint` and apply migrations. Phase B: Implement `VoiceCapturesController`, `NaturalLanguageDateParser`, `TaskScope` 90-day archival filter, and policy extras. Phase D: Add backend unit/integration tests.
3. **UI / UI-Integration** — Scaffold page components and wire design prototype JSX with `@rhino-dev/rhino-react` hooks inside `AppOwnerProvider`.
4. **Test** — Execute `bundle exec rails test` to ensure clean backend tests.
5. **Review** — Verify PRD compliance and final test reports.
